Docs / Quickstart

Gate one AI-generated Terraform plan.

The coding agent can propose HCL. Terraform or OpenTofu produces the structured plan. readtheplan evaluates that plan separately and returns a deterministic decision before merge or apply.

This workflow does not judge arbitrary chat, infer intent, run Terraform for you, refresh state, contact providers, or apply infrastructure.

1. Install

Python 3.10+ required. One command:

pip install readtheplan

Verify it works:

readtheplan --help

2. Generate structured plan JSON

Run Terraform or OpenTofu in the same reviewed environment you already use. readtheplan does not generate or refresh the plan.

terraform plan -out=tfplan -input=false
terraform show -json tfplan > plan.json

No safe repository plan available yet? Use a bundled static example:

git clone https://github.com/readtheplan/readtheplan.git
cd readtheplan/examples/02-dangerous-replacement
readtheplan agent-gate plan.json

3. Inspect the findings and gate decision

Use analyze for the human-readable finding report:

readtheplan analyze plan.json

Use agent-gate for the stable machine contract your workflow can enforce:

readtheplan agent-gate plan.json

Optional control annotations are review aids, not proof that a compliance requirement is satisfied:

readtheplan analyze --framework soc2 plan.json

4. Understand the output

Every change gets one of four risk tiers:

🟢 Safe

No-op, tag update, read-only change. A low-risk finding is not an approval.

🟡 Review

Security group rule change or minor config drift that needs a human look.

🟠 Dangerous

Instance replacement, IAM policy change, or database modification. Escalate before merge or apply.

🔴 Irreversible

Data deletion, KMS key destruction, or RDS termination. Expect the aggregate gate to block.

Risk tiers describe individual findings. proceed, warn, and block are aggregate gate decisions. readtheplan returns the decision; your CI or agent workflow enforces it.
