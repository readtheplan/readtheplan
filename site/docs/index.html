Compliance frameworks

readtheplan annotates every change with control IDs from these frameworks:

SOC 2

Security, availability, confidentiality controls. CC1-CC9 mappings.

ISO 27001

Annex A controls. A.5-A.18 coverage for infrastructure changes.

HIPAA

Administrative, physical, and technical safeguards for PHI data.
