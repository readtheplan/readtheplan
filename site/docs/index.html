Documentation

Start with one independent Terraform gate.

Generate Terraform or OpenTofu plan JSON, inspect the findings, and enforce a deterministic decision before merge or apply. CLI, CI, and MCP references use the same local contract; secondary adapters are documented separately.

Optional review catalogs

Six built-in catalogs can annotate findings for review: SOC 2, ISO 27001, HIPAA, PCI DSS, FedRAMP Moderate, and HITRUST. An annotation is not certification or proof that a control is satisfied.
