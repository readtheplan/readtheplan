Turn Terraform JSON plans into risk tiers, compliance evidence, and signed attestations.

Classifies every change as safe, review, dangerous, or irreversible. Works with Terraform and OpenTofu. SOC 2 / ISO 27001 / HIPAA evidence. Runs locally — no uploads, no accounts.

Agent gate

Give coding agents a deterministic stoplight.

readtheplan agent-gate returns a stable proceed/warn/block JSON contract so AI-generated infrastructure PRs cannot auto-approve dangerous or irreversible plans. 

{
  "schema": "rtp-agent-gate-v1",
  "decision": "block",
  "risk": "dangerous",
  "prohibited_next_actions": ["merge", "apply", "auto_approve"]
}

Evidence sample

Auditor-readable JSON, not screenshots.

Evidence envelopes map each plan finding to framework controls and can be signed with the optional readtheplan[sign] extra. 

{
  "schema": "rtp-evidence-v1",
  "framework": {"name": "soc2", "version": "2017-tsc"},
  "summary": {
    "resource_change_count": 3,
    "controls_touched": ["CC6.1", "CC6.6", "CC8.1"]
  }
}
