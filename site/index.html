Independent checks for AI-generated changes

Verify AI-generated infrastructure changes before they run.

readtheplan is a local second check for infrastructure changes proposed by AI agents. Start with Terraform or OpenTofu plan JSON: it explains the change, classifies its risk, and returns a deterministic decision before merge or apply. Raw plan data stays on your machine or CI runner.

Terraform/OpenTofu is the first gate. readtheplan does not evaluate arbitrary AI chat, source-code diffs, or an agent's intent. Generate a structured plan first.

Two layers, one decision

Risk tier in. Gate decision out.

Each Terraform or OpenTofu change is classified as safe, review, dangerous, or irreversible. The complete plan then receives one deterministic proceed, warn, or block decision for the surrounding agent or CI workflow to enforce.

Safe
No-op, tag update, read-only change
Review
Security group rule, minor config drift
Dangerous
Instance replacement, IAM policy change, DB modification
Irreversible
Data deletion, KMS key destruction, RDS termination

Independent approval boundary

          
The generator does not get the last word.

          
AI wrote the Terraform. Don't let it approve its own plan. A separate deterministic engine evaluates the structured artifact; your CI or agent workflow enforces the result.
