Local-first infrastructure review

Know what changes before it runs.

Auto-discovers plans, manifests, pipelines, playbooks, and configuration across a repository, then classifies them as safe, review, dangerous, or irreversible. Six built-in catalogs cover SOC 2, ISO 27001, HIPAA, PCI DSS, FedRAMP Moderate, and HITRUST. Runs locally with no accounts, no backend, and No plan upload.

Risk tiers

Four tiers. Zero noise.

readtheplan classifies the blast radius of every Terraform and OpenTofu change so reviewers can focus on what can actually break production.

Safe
No-op, tag update, read-only change
Review
Security group rule, minor config drift
Dangerous
Instance replacement, IAM policy change, DB modification
Irreversible
Data deletion, KMS key destruction, RDS termination
