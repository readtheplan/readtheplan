Know what your Terraform plan will actually do — before it runs.

Classifies every change as safe, review, dangerous, or irreversible. Produces compliance evidence for SOC 2, ISO 27001, and HIPAA. Runs locally — no uploads, no accounts, no backend.

pip install readtheplan && readtheplan analyze plan.json
CLI-first GitHub Action No plan upload SOC 2 · ISO 27001 · HIPAA Terraform + OpenTofu MIT license
Risk tiers
Safe
No-op, tag update, read-only change
Review
Security group rule, minor config drift
Dangerous
Instance replacement, IAM policy change, DB modification
Irreversible
Data deletion, KMS key destruction, RDS termination

Agent gate

    

      

        

          
          Block unsafe AI auto-approvals
        

        
Coding agents and agentic CI pipelines skip review. The agent-gate subcommand returns a deterministic proceed / warn / block decision your pipeline can act on without parsing human-readable output.

        

          
$ readtheplan agent-gate plan.json

          
{

          
  "decision": "block",

          
  "risk": "irreversible",

          
  "reason": "KMS key deletion scheduled",

          
  "changes": 1

          
}

Compliance evidence

    

      

        
SOC 2

        
CC6.1 · CC6.3 · CC6.6 · CC6.7

        
Trust Service Criteria controls annotated per change. Evidence output is auditor-ready JSON.

      

      

        
ISO 27001

        
A.8 · A.9 · A.12

        
Annex A control IDs mapped per resource change. Use with --framework iso27001.

      

      

        
HIPAA

        
§164.312(a)(1) · §164.312(e)

        
PHI-adjacent resource changes flagged with relevant safeguard sections.
